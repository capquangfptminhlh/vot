# ChoVot Pickleball

Marketplace vợt pickleball có xác thực người mua và người bán.

## Prototype hiện tại
- Trang chủ responsive desktop/mobile
- Marketplace mua vợt
- Chi tiết sản phẩm
- Đăng bán
- Xác thực người mua/người bán
- Hồ sơ người bán
- Định giá tham khảo
- Theo dõi giao dịch demo
- SEO foundations: title/meta/canonical/schema/robots/sitemap
- Website OS bootstrap + K0/D-Pre/D0 evidence

> Dữ liệu sản phẩm, giá, người bán, đánh giá và giao dịch hiện là dữ liệu demo. KYC, ngân hàng, escrow và vận chuyển thật chưa được tích hợp.
